# Project Status: Archived (2026-05)

This repository is no longer actively developed.

The product direction has shifted to a desktop-first Markdown editor with AI assistance:

**Successor:** https://github.com/cjhyy/writeflow

Code here is preserved for reference and the git history may be revived if needed. No new features, bug fixes, or PRs are expected in this repository.

## What this repo was

An AI-driven knowledge graph builder. Users described a learning topic; an Agent generated a structured mind-map skeleton and per-node Markdown documents. Built with React 19 / FastAPI / mem-deep-research.

## Why it was archived

The "galaxy / 3D" exploration phase did not produce a viable product. Direction pivoted to a focused desktop Markdown editor (Typora-style writing experience + AI assist), which has a clearer single-user value proposition and lower scope.
